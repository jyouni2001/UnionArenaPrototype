UNION ARENA

유니온 아레나 카드 배틀 게임을 Unity로 구현하는 개인 프로젝트입니다. 실제 카드 게임의 규칙을 바탕으로 카드 관리, 턴 진행, 전투 시스템을 구현하고 있습니다.

개발 환경
- Unity 6
- C#
- Universal Render Pipeline
- uGUI
- Git / GitHub

주요 구현 기능

- 플레이어별 게임 데이터 관리
- 카드 데이터 로드 및 카드 인스턴스 관리
- 덱, 패, 필드, 라이프, 트래시, 리무브 영역 관리
- 필드 구분
- 턴 및 페이즈 진행
- AP를 이용한 카드 비용 처리
- 카드 드래그 앤 드롭
- 트래시와 리무브 카드 목록 확인
- 기본 전투 및 상대 AI 기능 개발

프로젝트 목표

카드 게임의 규칙을 코드로 구조화하고, 데이터 관리와 UI를 분리하여 유지보수하기 쉬운 구조를 만드는 것을 목표로 하고 있습니다.
현재 기본적인 게임 시스템을 구현하고 있으며, 카드 효과 처리와 온라인 대전 기능 등을 단계적으로 개발할 예정입니다.
